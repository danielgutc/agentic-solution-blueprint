## Status values

| Status | Meaning |
| --- | --- |
| Designed | Defined and traceable; implementation is incomplete. |
| In progress | Active design, implementation, infrastructure, or verification work. |
| Implemented | Accepted implementation and verification evidence exists. |
| Deferred | Outside the current planning horizon. |
