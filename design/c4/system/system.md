# System

## Purpose

Describe the software system as a whole, including its scope, primary actors, external systems, and overall responsibilities.

## Summary

Summarize the system in a few sentences.

## Actors

List the primary users, operators, or external actors that interact with the system.

## External systems

List the external systems, services, or organizations that exchange information with the system.

## Responsibilities

Describe the main responsibilities and outcomes owned by the system.

## Boundaries

Describe what is inside the system scope and what remains outside it.

## Open questions

Capture unresolved system-level questions, assumptions, or follow-up decisions.

## Diagrams

Reference the system-level diagrams stored in the adjacent `_diagrams/` folder.
