# Agent Topology

## Scope

Coordinate blueprint evolution work spanning instructions, templates, skills, and sync governance.

## Roles

- Governance maintainer
- C4 authoring maintainer
- Diagram tooling maintainer

## Role boundaries

- Governance maintainer owns `AGENTS.md` and sync policy.
- C4 authoring maintainer owns C4 artifact instructions and skills.
- Diagram tooling maintainer owns diagram standards and export validation.

## Handoffs and contracts

- Governance updates hand off required artifact or skill updates as explicit TODO contracts.
- C4 updates hand off diagram validation requests with expected outputs.

## Escalation path

- Escalate cross-role conflicts to governance maintainer for final policy decision.

## Approval ownership

- Governance maintainer approves final blueprint-governance sync scope.
