# Navigation Standard

## Foundation pages

- Use `Related foundation documents` for sibling navigation.

## C4 pages

- Prefer meaningful labels over generic `In this section`.
- Use:
  - `Contained containers` in system-containers page.
  - `Contained components` in container pages.

## Diagram navigation

- Prefer diagram-to-diagram links for drill-down.
- For container diagrams, component nodes should link to `_code-diagrams/*.svg` only when those files exist.
