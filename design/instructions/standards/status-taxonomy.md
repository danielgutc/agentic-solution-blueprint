# Status Taxonomy

Use this status vocabulary across dashboards and progress trackers.

## Allowed statuses

- `Not started`
- `In progress`
- `Designed`
- `Approved`
- `Implemented`

## Usage notes

- `Designed` means the artifact exists in an accepted design form but is not yet implementation-ready.
- `Approved` means the current abstraction gate is explicitly accepted.
- `Implemented` means runtime code or executable behavior exists, not just design artifacts.

Avoid introducing ad hoc statuses unless this file is updated first.
