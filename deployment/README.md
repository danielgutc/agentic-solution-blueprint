# Deployment

Repository-owned deployment topology, environment composition, infrastructure as code, and deployment-specific validation live here.

Keep a service's image build inputs with its owning implementation unit when they are part of that unit's package. Keep multi-unit composition and environment or platform definitions here. Do not create provider, environment, or container directories until the approved delivery model requires real files.

Record concrete deployment technology, commands, trust boundaries, recovery, and promotion decisions in `design/foundation/tech.md` and `design/foundation/delivery.md`.
