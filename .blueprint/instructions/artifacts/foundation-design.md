# Foundation Artifact: design.md

## Purpose

Capture enduring architecture decisions and tradeoffs at system level before C4 decomposition.

## Canonical structure

- Use `.blueprint/templates/foundation/design.template.md`.

## Authoring rules

- Keep this level above container decomposition.
- Explain major responsibilities and boundaries the C4 system level will elaborate.
- Record architecture decisions with rationale and tradeoffs.
- Keep open questions explicit and decision-oriented.

## Quality checklist

- System overview is clear to non-implementers.
- Architecture decisions justify chosen direction.
- Open questions are actionable and bounded.
