# Draw.io Files

## Rules

- Follow [diagram tooling](../standards/diagram-tooling.md) for source, SVG export, link preservation, and verification.
- Use one concern and one C4 abstraction level per diagram.
- Keep titles, identifiers, names, boundaries, and relationship direction aligned with the owning Markdown artifact.
- Use relative links to existing next-level SVG diagrams for drill-down; do not link to future placeholders.
- Preserve editable `.drawio` source beside its committed `.svg` export.
