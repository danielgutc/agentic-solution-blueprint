# AGENTS Cleanup Candidates

Use this list when slimming `AGENTS.md` in future passes.

## Keep in AGENTS

- behavioral contract and precedence
- workflow and approval gate requirements
- contribution and blueprint sync policy

## Move out of AGENTS (or keep only as links)

- exact artifact table schemas
- detailed matrix column definitions
- repeated naming/status/navigation details
- diagram tooling operational checklists

## Contradiction checks

- verify no duplicated normative rule appears with different wording across:
  - `AGENTS.md`
  - `.blueprint/instructions/process/*`
  - `.blueprint/instructions/artifacts/*`
  - `.blueprint/instructions/standards/*`

## Merge readiness signal

- `AGENTS.md` points to modular instructions for detail
- modular files contain canonical detail
- templates and samples match modular rules
