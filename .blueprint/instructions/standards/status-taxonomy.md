# Status Taxonomy

## Lifecycle and task status

- `Not started`
- `In progress`
- `Ready for review`
- `Approved`
- `Implemented`
- `Verified`
- `Blocked`

## Readiness criterion status

- `Not assessed`
- `Pass`
- `Fail`
- `Accepted exception`

## Meaning

- `Approved` means the current design or governance decision has explicit acceptance for a named scope.
- `Implemented` means executable behavior exists, not only design, scaffolding, adapters, or placeholders.
- `Verified` means the required independent or integrated evidence passes.
- `Blocked` requires a named condition and owner.
- `Accepted exception` requires rationale, owner, expiry or trigger, and compensating evidence.

Do not invent synonymous statuses in project dashboards. Update this standard first when a genuinely distinct state is required.
