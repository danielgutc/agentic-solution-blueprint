# Product

## Purpose

Use this file to describe the product vision for the project created from this blueprint.

## Recommended sections

- Summary
- Users or actors
- Problem to solve
- Core outcomes
- Goals
- Non-goals
- Assumptions

## Authoring guidance

- Keep this file business-focused rather than implementation-focused.
- Describe the value the system should create before describing how it works.
- Keep goals and non-goals explicit so later design decisions stay grounded.
