# Requirements

## Goal

Define the initial repository structure for the project.

## Requirements

- Keep the root focused on shared workflow, tooling, and testing until concrete solution components are ready.
- Keep steering and specs under `.design/`.
- Keep stable project guidance under `.design/foundation/`.
- Keep enduring architecture under `.design/c4/`.
- Keep Codex-specific files under `.codex/`.
- Use PlantUML for architecture and structure diagrams.
