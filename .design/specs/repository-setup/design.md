# Design

## Summary

The repository separates project design artifacts from Codex-specific files and from implementation components.

## Decisions

- `.design/foundation/` contains stable project guidance.
- `.design/c4/` contains the enduring architecture model.
- `.design/specs/` contains change-focused planning.
- `.codex/` contains assistant-specific files only.
- `tools/` and `tests/` are the only runtime-adjacent top-level folders for now.
- Additional solution components will be added later once the initial architecture is decided.
